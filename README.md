# паВук

**Язык программирования:** HTML

**Назначение:** HTML-страницы, веб-разметка, учебные веб-проекты и связанные статические материалы.

> ПаВук плетёт разметку, а CSS и JavaScript держит каждый на своей паутинке.

## Структура каталогов

```text
Labs/
Projects/<site>/index.html
Projects/<site>/styles/
Projects/<site>/scripts/
Experiments/
Documentation/
```

Реальные файлы лабораторных и проектов добавляются в соответствующие каталоги. Для нескольких C-программ, Python-скриптов или веб-сайтов заводи отдельную папку проекта.

## Запуск и сборка

Открой `index.html` проекта в браузере. Для локальной разработки и загрузки модулей запусти сервер из каталога сайта:
```sh
cd Projects/<site>
python3 -m http.server 8000
```
Затем открой `http://localhost:8000`. CSS и JavaScript размещай рядом с конкретным сайтом в `styles/` и `scripts/`.

## Учебные работы и проекты

Пока реальные работы в репозитории не добавлены. По мере готовности указывай здесь название, краткую цель и ссылку на папку каждой работы или проекта. Демонстрационные заглушки не используются.

## Будущие дополнения

Добавляй новые лабораторные работы и самостоятельные проекты в соответствующие каталоги. Для каждого самостоятельного проекта сохраняй локальные инструкции по запуску, сборке и зависимостям.
